## 🔥 Ver.3 — 1인1역 직접 말하기 버전 (얼굴 출연, 18초)

**컨셉**: 카메라 = 시청자. 창업자가 직접 시청자한테 말 거는 구조.  
화려한 편집 없이 **얼굴 + 화면 + 말** 세 가지만으로 완결.  
1인1역 원테이크 느낌이 신뢰감을 높임.

---

### 샷 스크립트

|---|---|---|---|
| **0~1** | 화면 밖에서 얼굴이 카메라 쪽으로 빠르게 확 다가옴 | *(없음)* | |

| **6~11** | 노트북/폰 화면을 카메라 앞으로 들이밈. 카피·가격 입력 장면. 실행. | **"제품 카피나 가격 넣고 돌리면"** | `arabesque.cc` |

### 촬영 가이드

**카메라 세팅**
- 삼각대 없이 핸드헬드 or 셀카봉 권장 — 약간의 흔들림이 자연스러운 긴장감 줌
- 0~1초 "다가오기" 장면: 카메라를 고정하고 몸이 렌즈 쪽으로 빠르게 접근
- 10~13초 화면 장면: 폰을 들고 찍으면 화면 글씨 안 보임 → **화면 녹화 영상을 편집 시 PIP로 합성** 권장

**원테이크 포인트**
- 대사 사이 침묵을 두려워하지 말 것 — 0.5초 간격이 리듬 만듦
- 4~7초 손동작은 작게, 얼굴 표현으로 감정 전달

**음악**
- 없거나 아주 낮게. 목소리가 주인공.
- 14초 결과 등장 시 짧은 'pop' 효과음 1회

### 샷 스크립트

| 초 | 화면 | 오디오 / 텍스트 |
|---|---|---|
| 0~1 | 키보드 타이핑하는 손 클로즈업. 갑자기 멈춤. | 타닥타닥… (멈춤) |
| 2~3 | 얼굴 클로즈업. 카메라 정면. 입 모양으로만. | 텍스트 오버레이: **"이게 팔릴까?"** |
| 4~5 | 화면 밖에서 목소리. 본인 표정 → 황당 | 동료 목소리 OFF: **"설문 돌려!!"** |
| 6~7 | 카메라 보며 되묻는 얼굴 | 본인: **"누구한테요?"** |
| 8~9 | 다시 목소리. 본인 표정 → 더 황당 | 동료 목소리 OFF: **"돌아다녀라고!!"** |
| 10 | 카메라 정면. 한숨. 눈 감았다 뜸. | (무음) |
| 11~13 | 화면으로 전환: arabesque.cc 접속. 카피 3줄 입력. 실행 클릭. | 텍스트: **"그냥 여기다 넣음"** |
| 14~16 | 결과 화면 클로즈업. 도넛 차트 등장. | 텍스트: **"58초 뒤"** → **"200명 응답 완료"** |
| 17~18 | 얼굴 + 화면 PIP. 결과 보며 끄덕임. | 텍스트: **"카피 B가 61% 선호"** |
| 19~20 | 카메라 정면. 어깨 으쓱. | 텍스트 풀스크린: **arabesque.cc** |

### 편집 포인트

- **0~10초**: 컷 없이 원테이크로 찍을수록 더 자연스럽고 공감됨
- **10초 전환**: 음악 ON (클린한 전자음으로 분위기 전환 명확히)
- **11~20초**: 화면 녹화 + 얼굴 PIP 구성. 화면이 90%, 얼굴 썸네일이 우하단 10%
- **텍스트**: Pretendard ExtraBold, 흰색, 화면 중앙 하단
- **"58초 뒤" 텍스트**: 타이머 애니메이션 효과 추가하면 임팩트 강해짐

## 편집 가이드

### 텍스트 스타일
- 폰트: Pretendard ExtraBold (제품 디자인 시스템 일치)
- 색상: 흰색 텍스트 + 검정 또는 반투명 배경
- 강조어는 **Primary Blue (#0066FF)** 또는 노란색 하이라이트

### 컷 리듬
- 0~12초: 2~3초 컷 (긴박감)
- 12~42초: 제품 화면 위주, 컷보다 화면 내 모션
- 42~58초: 느린 컷, 안정감

### 자막
- 전 구간 한국어 자막 필수 (무음 시청 대비)
- 핵심 수치는 텍스트 오버레이로 2중 강조

### 음악
- 장르: Lo-fi tech / minimal electronic
- 템포: 초반 긴박 → 중반 클린 → 후반 확신
- 무료 라이선스: Pixabay, Uppbeat 활용 가능
